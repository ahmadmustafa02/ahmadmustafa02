### Warrant — authorization for AI agents

<p>
  <a href="https://warrant-lab.vercel.app/"><img src="https://img.shields.io/badge/Live_lab-warrant--lab.vercel.app-0E7490?style=for-the-badge&logo=vercel&logoColor=white" alt="Open the Warrant lab"></a>
  <a href="https://github.com/ahmadmustafa02/warrant"><img src="https://img.shields.io/badge/Source-GitHub-111827?style=for-the-badge&logo=github&logoColor=white" alt="Warrant source"></a>
  <img src="https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white" alt="TypeScript">
  <img src="https://img.shields.io/badge/MCP-111827?style=for-the-badge" alt="Model Context Protocol">
</p>

A provenance guard for tool-using agents. It freezes the user's original request and blocks sensitive tool calls that request did not authorize. It ships as a framework-free TypeScript guard and a CLI proxy (`@warrant-lab/guard`, `@warrant-lab/cli`). I designed and built it as the capstone of an AI engineering internship at Arbisoft.

### When AI agents change dependencies

<p>
  <a href="https://github.com/ahmadmustafa02/ai-agent-dependency-vulns"><img src="https://img.shields.io/badge/Read_the_study-GitHub-111827?style=for-the-badge&logo=github&logoColor=white" alt="Read the dependency study"></a>
  <img src="https://img.shields.io/badge/OSV--Scanner-111827?style=for-the-badge" alt="Scanned with OSV-Scanner">
  <img src="https://img.shields.io/badge/odds_ratio-2.06-86198F?style=for-the-badge" alt="Odds ratio 2.06">
</p>

17,727 pull requests from Devin, Codex, Copilot, Cursor, and Claude Code, matched with human pull requests from the same repositories and time windows. Every changed manifest was scanned with OSV-Scanner. AI-agent pull requests introduced a known-vulnerable dependency **17.17%** of the time, against **9.14%** for human pull requests (95% CI 1.76–2.41).

### Cross-project vulnerability detection

<p>
  <a href="https://github.com/ahmadmustafa02/cross-project-vulnerability-detection"><img src="https://img.shields.io/badge/Read_the_study-GitHub-111827?style=for-the-badge&logo=github&logoColor=white" alt="Read the cross-project study"></a>
  <img src="https://img.shields.io/badge/CodeBERT-111827?style=for-the-badge&logo=huggingface&logoColor=FFD21E" alt="CodeBERT">
  <img src="https://img.shields.io/badge/PrimeVul-9_codebases-0E7490?style=for-the-badge" alt="Nine PrimeVul codebases">
</p>

Random Forest and CodeBERT, trained and tested across nine PrimeVul codebases, including Linux and Chrome, with one shared occlusion explainer. Predictive performance collapsed across projects. Mean MCC fell from **0.189 to 0.005** for the classical model and from **0.169 to 0.050** for CodeBERT. Explanation stability fell too, by less than performance did.
